A single-file, zero-dependency web app with 100 Node.js interview questions and answers — each with a runnable code example. Built as part of an ongoing Interview Prep Series covering JavaScript, React, Angular, JS Coding Questions, TypeScript, and now Node.js.

**[Live Demo →](https://sharfuddin1984.github.io/nodejs-interview-questions/)**


## Features

- **100 curated questions** across 11 categories — Basics & Runtime, Modules & npm, Event Loop & Async, File System, Streams & Buffers, HTTP & Networking, Express & Middleware, Error Handling & Debugging, Process/Cluster/OS, Security & Performance, and Testing
- **Syntax + code examples** for every answer, not just theory
- **Live search** across questions, answers, code, and category
- **Category filter pills** with live counts
- **Bookmark system** — save questions for later review, persisted via `localStorage`
- **Accordion UI** — clean, distraction-free expand/collapse per question
- **Dark theme** — JetBrains Mono for code, Space Grotesk for UI
- **Zero dependencies** — a single `index.html` file, no build step, no frameworks

## Tech Stack

Vanilla HTML, CSS, and JavaScript. No frameworks, no bundler, no npm install required.

## Running Locally

Clone the repo and open `index.html` directly in a browser:

```bash
git clone https://github.com/sharfuddin1984/nodejs-interview-questions.git
cd nodejs-interview-questions
open index.html
```

No server or build step needed.
